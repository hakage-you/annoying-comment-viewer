# アプリ利用ガイド

`annoying-comment-viewer` の基本的な使い方を説明します。

## アプリの起動
1. アプリケーション（`annoying-comment-viewer.exe`）を起動します。
2. 初回起動時は「Google API Setup」画面が表示されます。[Google Cloud Console ガイド](./google_setup.md) で取得したクライアント ID とシークレットを入力し、保存（Save and Continue）を押してください。
3. ブラウザが開くので、Google アカウントでログインし、「すべて許可」をクリックしてアプリに権限を与えてください。

## コメントビューワーの設定
1. 設定画面（Settings）が表示されます。
2. **YouTube Video ID**: 配信ページの URL または Video ID（例: `dQw4w9WgXcQ`）を入力します。
3. **TTS（音声合成）設定**:
   - `読み上げを有効にする` にチェックを入れるとコメントが読み上げられます。
   - `TTS エンジン` で、VOICEVOX / COEIROINK など、お使いのエンジンを選択してください。
   - `話者 ID` / `スタイル ID` で、好みの声を選択します。
4. **表示設定**:
   - `常に手前に表示`：他のウィンドウより前面に表示されます。
   - `Sticky モード`：コメントが画面を流れるのではなく、ランダムな位置に固定されます。
5. 「Start Monitoring」をクリックすると、コメントの取得が開始されます。

## 機能説明
- **トレイアイコン**: タスクバーのアイコンを右クリックすると、読み上げの ON/OFF、Stickyモードの切り替え、表示のリセットなどが可能です。
- **配置モード**: Stickyモード中は、配信画面の邪魔になる場所を物理的に遮るようにコメントが重なっていきます。
