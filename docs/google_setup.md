# Google Cloud Console セットアップガイド

`annoying-comment-viewer` を利用するために必要な OAuth 2.0 クライアント ID / シークレットの取得手順です。

なにこれ？ → [Q&A](#qa)

## 1. プロジェクトの作成
1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. 上部ツールバーのプロジェクト選択ドロップダウンをクリックし、「新しいプロジェクト」を選択します。
3. プロジェクト名（例: `MyCommentViewer`）を入力し、「作成」をクリックします。

## 2. YouTube Data API v3 の有効化
1. 左側のナビゲーションメニューから **[APIとサービス] > [ライブラリ]** を選択します。
2. 検索バーに `YouTube Data API v3` と入力し、表示された項目を選択します。
3. 「有効にする」ボタンをクリックします。

## 3. OAuth 同意画面の設定
1. 左メニューから **[APIとサービス] > [OAuth 同意画面]** を選択します。
2. User Type で **[外部]** を選択し、「作成」をクリックします。
3. **アプリ情報**:
   - アプリ名: `annoying-comment-viewer`
   - ユーザーサポートメール: 自分のメールアドレス
   - デベロッパーの連絡先情報: 自分のメールアドレス
4. 「保存して次へ」を数回押し、最後の「ダッシュボードに戻る」まで進めます。
5. **重要**: 「テストユーザー」のセクションで「+ ADD USERS」をクリックし、自分の Gmail アドレスを追加して保存してください。これを忘れるとログイン時にエラーになります。

## 4. 認証情報の作成
1. 左メニューから **[APIとサービス] > [認証情報]** を選択します。
2. 上部の **[+ 認証情報を作成] > [OAuth クライアント ID]** を選択します。
3. アプリケーションの種類で **[デスクトップ アプリ]** を選択します。
4. 名前（例: `Desktop Client`）を入力し、「作成」をクリックします。
5. 表示された **クライアント ID** と **クライアント シークレット** をコピーして、アプリの初期設定画面に入力してください。

## Q&A

### Q. なぜこの手順が必要なのか？

A. 開発者のGoogleアカウントに依存せずにGoogleのAPIを叩くためには、あなたのGoogleアカウントを利用するようにするのが都合がいいと判断したからです。

### Q. 自分のGoogleアカウントでAPIを叩くことによるリスクは？

A. Youtube APIには無料利用枠があり、超過するとしばらくAPIが利用できなくなります。(2026/4/6 現在情報)

### Q. 無料？

A. 無料です。(2026/4/6 現在情報) Googleが変わらない限り。
