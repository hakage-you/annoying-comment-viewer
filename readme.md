## 開発方法

### 初回セットアップ(開発者向け)

`git clone` してきたらリポジトリのディレクトリで `npm install` して必要なパッケージをインストールしてね。

### electron(プログラム全体)の開発

- `npm run dev` コマンドを実行すると electron として実行されるよ。
- vscode のデバッグを利用できるよ。

### UI（見た目の部分だけ）の開発・デバッグ

- `npm run dev:ui` コマンドを実行すると、ダミーのコメント等で見た目のテストがしやすいよ。

### ビルド
1. Webpack を使って本番用にトランスパイルされたソースコードを `npm run build` コマンドで public フォルダに出力してね。
2. その後、`npm run make` コマンドを実行すると、 out フォルダ以下に配布用のアプリケーションがビルドされるよ。
